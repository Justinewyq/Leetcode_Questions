# 470. Implement Rand10() Using Rand7()

rand{N^2} = rand(N - 1)*N + randN
* Get rand49() via rand7().
* We have 1- 49, discard 41-49.
* We have 1- 40. rand10() = x % 10 + 1

Each rand10(), will call rand7() ___ times?\
E = 当前成本 + 失败概率 * E\
E = 2 + 9/49 * E\
E = 2.45

```python
class Solution:
    def rand10(self):
        """
        :rtype: int
        """
        rand40 = 49

        while rand40 > 40:
            rand40 = (rand7() - 1) * 7 + rand7()

        return rand40 % 10 + 1
```
