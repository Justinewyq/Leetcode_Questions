# 498. Diagonal Traverse

Traverse has 2 directions:
1. UP:\
   Direction: (x, y) -> (x - 1, y + 1)

   Next Row (In order):
   * (x, y + 1)  # First try right.
   * (x + 1, y)  # Then try downward.
   
3. DOWN:\
   Direction: (x, y) -> (x + 1, y - 1)
   
   Next Row (In order):
   * (x + 1, y)  # First try downward.
   * (x, y + 1)  # Then try right.

* Time: O(n * m)
* Space: O(n * m)

```python3
class Solution:
    def findDiagonalOrder(self, mat: list[list[int]]) -> list[int]:
        x = y = 0
        dir = 1
        res = []
        m = len(mat)
        n = len(mat[0])
        dir1 = [-1, 1]
        dir2 = [1, -1]

        for i in range(m + n - 1):
            res.append(mat[x][y])

            if dir == 1: # UP
                while x + dir1[0] >= 0 and y + dir1[1] < n:
                    x = x + dir1[0]
                    y = y + dir1[1]
                    res.append(mat[x][y])
                
                if y + 1 < n:
                    y = y + 1
                else:
                    x = x + 1

                dir = 2
            else: # DOWN
                while x + dir2[0] < m and y + dir2[1] >= 0:
                    x = x + dir2[0]
                    y = y + dir2[1]
                    res.append(mat[x][y])
                
                if x + 1 < m:
                    x = x + 1
                else:
                    y = y + 1

                dir = 1
        return res
```
