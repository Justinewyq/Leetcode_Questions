# 2013. Detect Squares

Data Structure: Counter(). Count the number of points in each position.

* Find the diagnose point with [a, b]. (Need to be Square.)
* Update result.

## Complexity
* Time (count function): O(N)
* Space (count function): O(N)
  * N = number of points

```python3
class DetectSquares:
    
    def __init__(self):
        self.dic = Counter()
    def add(self, point: list[int]) -> None:
        if (point[0], point[1]) in self.dic.keys():
            self.dic[(point[0], point[1])] += 1
        else:
            self.dic[(point[0], point[1])] = 1

    def count(self, point: list[int]) -> int:
        a, b = point[0], point[1]
        res = 0
        for x1, y1 in self.dic.keys():
            if abs(x1- a) != 0 and abs(x1- a) == abs(y1 - b):
                res += self.dic[(x1, y1)] * self.dic[(x1, b)] * self.dic[(a, y1)]
                    
        return res
```
