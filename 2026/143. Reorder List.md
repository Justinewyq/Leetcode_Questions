# 143. Reorder List

Double Pointers and merge.

* Time: O(length)
* Space: O(length)

```python3
class Solution:
    def reorderList(self, head: ListNode | None) -> None:
        """
        Do not return anything, modify head in-place instead.
        """
        mylist = []
        cur = head

        while cur:
            mylist.append(cur)
            cur = cur.next
        
        l = 0
        r = len(mylist) - 1
        cur = ListNode(0, head)
        while l < r:
            cur.next = mylist[l]
            cur.next.next = mylist[r]
            cur = cur.next.next
            l += 1
            r -= 1
        
        if l == r:
            cur.next = mylist[l]
            cur = cur.next
        cur.next = None
```
